# Добро пожаловать в стаю Paloma! 🕊️

> **Paloma Chain** — это реализация на Go децентрализованной сети автоматизации для смарт-контрактов,  
> работающей в экосистемах **Cosmos**, **EVM**, **Solana** и **Polkadot**.  

Для разработчиков кроссчейн-решений, которым нужен одновременный контроль над несколькими смарт-контрактами в разных блокчейнах, Paloma предлагает:  

- Децентрализованную и консенсусную доставку сообщений  
- Быстрое получение состояния  
- Низкие издержки на вычисления  
- Мощную систему аттестации  

Все это делает возможным **масштабируемое кроссчейн-исполнение смарт-контрактов** с любыми источниками данных.  

Это приглашение для новых участников нашей стаи!
